# 衣物提取规则

适用对象：单章提取时的 `clothing` 数组。字段定义见 `schemas/clothing.schema.json`。

## 1. 提取单元：角色 + 场景

衣物按 **"角色 + 场景"** 组织，而不是按"一件衣服"。

- `character`：穿着者姓名。必须与本章 `characters` 中的 `name` 一致（先提取人物，再挂衣物）。
- `scene`：场景简述，说明"在什么场合穿的"。用 5–20 字概括，例如 `初登场`、`雪夜赶路`、`婚宴`、`战中负伤后`、`易容潜入`。
- 同一角色在同一场景穿整套装束 → **合并为一条**，写进 `description` 与 `color_material`。
- 同一角色在不同场景各一套 → **分成多条**，各自带 `quote`。
- 汇总阶段同角色同场景出现多套时，按 `aggregation-rules.md` 加序号。

## 2. 什么算衣物

**提取**：

- 衣服本体：长衫、儒袍、劲装、短打、裙、襦、袄、披风、斗篷、氅。
- 甲胄戎装：铠甲、锁子甲、皮甲、战袍、护腕、护心镜。
- 配饰穿戴物：腰带、玉带、头巾、发冠、簪、钗、耳饰、项链、戒指、香囊、玉佩、扇子（随身持握且作为身份标志时归衣物）。
- 鞋帽：靴、履、草鞋、斗笠、毡帽。
- 遮掩与易容相关穿戴：面纱、斗篷兜帽、面具。

**不提取**：

- 纯材质/颜色的孤立词（"白衣"若无人穿就不算）。
- 武器类（剑、刀、弓）→ 归 `items`。
- 物品类（包裹、行囊、灯笼）→ 归 `items`。
- 身体特征（长发、疤痕、胡须）→ 归 `appearance`。

边界不清时：**穿在身上的 / 决定外观的** → 衣物；**手持的、可独立存在的器物** → 物品。扇子、玉佩等两可项：作为穿戴配饰写衣物，作为功能器物写物品，同一章内只写一处，不要两处重复。

## 3. 字段

| 字段 | 约定 |
|---|---|
| `character` | 穿着者姓名；无名龙套的衣物不提取 |
| `scene` | 场景简述；不要写"本章""此时"这类无信息词 |
| `description` | 衣物描述，原文用词优先（`青布直裰`、`玄色劲装`） |
| `color_material` | 颜色/材质，如 `青布`、`玄色缎面，金线滚边`；原文没写就写 `""` |
| `phase_hint` | 扩展字段：与同章该角色的 `characters[].phase_hint` **逐字一致**；判断不了写 `""` |
| `quote` | **必填**，原文引用，≤ 50 字 |

`phase_hint` 让汇总阶段能把衣物卡挂到正确的阶段卡上（汇总后写入 `phase_id`）。只描述穿着者的
时期处境，不要复述原句、不要写章号。

## 4. 原文引用（quote）—— 硬要求

- **必须逐字来自本章原文**，不得改写、概括、拼接不相邻片段。
- **长度 ≤ 50 字**；超长时截取**包含该衣物判定的最小完整片段**，不要用省略号掩盖跨段拼接。
- 一个 `quote` 只服务一条衣物记录；多条共用时要各自复制。
- 汇总阶段会把 `quote` 写入衣物卡的"原文依据"，并可用 `.dsh/skills/character-extraction/scripts/validate_extraction.ts` 回查原文；**查不到即视为无效提取**。

## 5. 只提取实际描写

- 只提取原文**实际写出来**的穿着。不写"应当穿""大约是"。
- 不推断季节/身份对应的服饰（原文说"锦衣"就写"锦衣"，不要补"因为他是富商"）。
- 不合并跨章信息：本章没写颜色就不要用上一章的颜色补。
- 原文仅有笼统一句（`身穿白衣`）就只写这一句，`color_material` 写 `白色`，不要扩写款式。

## 6. 变化与更换

- 同一场景内明确写出换装（`披上外袍`）→ 拆成两条，`scene` 用 `换装前` / `换装后` 区分。
- 衣物破损、撕裂、沾染 → 写进 `description`，算同一条的补充而非新条目；除非原文视作新装扮。
- 脱去/失去衣物（`褪去外袍`）不单独成条，除非该动作改变了外观判定。

## 7. 汇总阶段：挂到阶段

- 归并键是 `character`（归到角色主名）+ `scene`；同一"角色+场景"多套时加序号（一）（二）。
- 每张衣物卡写入 `character_id`（角色 ID）与 `phase_id`（该卡首个章号落在的阶段 ID），
  使衣物可关联到具体阶段；同一角色在不同阶段的多套衣物因此互不混淆。
- 详见 `references/aggregation-rules.md` 第 4 节。

## 8. 自检清单

- [ ] 每条都有非空 `character`、`scene`、`description`、`quote`。
- [ ] `character` 与本章 `characters` 的姓名一致。
- [ ] `phase_hint` 与本章该角色的 `phase_hint` 一致（或为空串）。
- [ ] 每条 `quote` 都能在本章原文中逐字找到，且 ≤ 50 字。
- [ ] 没有把武器/器物写进 `clothing`。
- [ ] 没有颜色/材质的推断补全。
