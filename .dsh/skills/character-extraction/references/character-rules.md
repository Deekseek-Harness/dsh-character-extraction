# 人物提取规则

本 skill 的人物信息是**二维**的：

| 维度 | 文件 | 回答的问题 | 生命周期 |
|---|---|---|---|
| **实体（Character）** | `cards/characters/<姓名>/index.md` | 这个人**是谁** | 跨阶段稳定，全篇不变 |
| **阶段（Phase / Look）** | `cards/characters/<姓名>/phase_XX_<标签>.md` | 这个人**在某段章节里是什么样** | 只在该章节范围内成立 |

生图或下游使用时，**只组合「实体卡 + 目标阶段卡」，不使用实体卡字段的并集**。年龄、身份、
外貌、着装、别名、关系都按阶段归属；实体卡只留跨阶段稳定的身份锚点。

本文件同时约束两处：

- **逐章提取**（单章子代理）：产出本章快照 + `phase_hint` 提示，**不做阶段切分**；字段定义见
  `schemas/character.schema.json`。
- **汇总阶段**（`character-aggregator`）：按章序把逐章快照切分成阶段，生成实体卡与阶段卡；
  切分流程见 `references/aggregation-rules.md`，字段定义见
  `schemas/character-entity.schema.json` 与 `schemas/character-phase.schema.json`。

## 1. 提取范围

- **只提取本章出现的人物。** 判断依据是本章原文，不是全书知识、不是前几章的记忆。
- 不要因为某人在前文重要就补写他；不要因为某人"应该在场"就写他。
- 不要跨章累积：处理第 N 章时，前 N-1 章的提取结果不属于本章输入。
- 逐章条目的 `age` / `identity` / `appearance` / `aliases` 都是**本章值**；书僮时期的别名
  不要写进将军时期的章。

## 2. 什么算"人物"，什么不算

**提取**（满足任一条）：

- 有姓名（含姓、名、字号、法号、绰号）。
- 有对话（引号内的发言），且说话人可判定。
- 有明确身份指称并能稳定指代某个体（如"那掌柜的""李府管家"），本章内可追踪。

**不提取（无名龙套）**：

- 无姓名、无对话、仅一笔带过：`众人`、`百姓`、`群雄`、`一个伙计`、`数名侍卫`、`路人`。
- 群体称呼：`三人`、`诸将`、`众弟子`。哪怕群像描写很详细也不提取。
- 纯环境拟人：`风`、`影子`。除非原文明示为人物。

判定不确定时：**倾向不提取**。宁可漏一个龙套，不要造一个角色。

## 3. 别名、绰号、称号（分阶段）

- 逐章：全部放进本章 `aliases` 数组，**不要**为同一人物的别名单独建条目。
- 覆盖：绰号（`黑旋风`）、称号（`及时雨`）、尊称（`李老爷`）、贬称（`那厮`，能确定指代时）、
  法号/道号、化名、官职代称（`李提辖`）、排行称呼（`三郎`）。
- `name` 取**最正式、最具辨识度**的称呼：优先"姓+名"，无姓名则取最稳定的称呼。
- 别名要能在本章原文中找到出处；不要凭读音猜测变体、不要补全姓氏。
- 本章 `aliases` 去重，不含 `name` 本身。

汇总时按阶段归属：

- **实体卡 `aliases`** 只放**跨阶段通用**称呼（覆盖 ≥ 60% 阶段，或覆盖 ≥ 3 个阶段）。
- **阶段卡 `allowed_names`** 放该阶段**实际出现**的称呼（主名 + 该阶段出现的别名）。
- **阶段卡 `forbidden_names`** 放只属于**其他阶段**的称呼，例如将军时期的阶段卡里禁止出现
  `卖面郎`、`店家`。硬要求：`forbidden_names` 与 `allowed_names` **不得有交集**（机器校验会报错）。
- 逐章出现了多个不同人物共用的称呼（同名不同人）时，该称呼不进任何人的实体卡 `aliases`，
  只在对应阶段卡的 `allowed_names` 保留，并在卡片正文注明同名情况。

## 4. 关系（分阶段）

逐章记录规则：

- 关系必须**标明方向**：`target` 是被指向的对方，`type` 是从本角色出发看过去的关系。
- 方向示例：`{"target": "李寻欢", "type": "结义兄弟"}` 写在角色 A 的条目里，表示"A 视李寻欢为结义兄弟"；不要依赖对方条目反推。
- 反向关系可在对方条目中各自记录，两侧独立、不互相推导。
- 关系类型用简短稳定的词：`父`、`母`、`子`、`女`、`兄`、`弟`、`姐`、`妹`、`夫妻`、`师徒`、`师兄弟`、`主仆`、`上下级`、`结义兄弟`、`同门`、`仇敌`、`旧识`、`恋慕`、`未婚夫妻`、`护卫`、`君臣`、`同僚`、`对手`。
- `target` 必须是**人名**，不是代词。原文只出现"她""那人"时，无法确定就标 `[不确定]`。
- 每条关系建议带 `quote`（可选字段），用于卡片"关系-依据"列；没有引文时该列留空。
- 单章内关系证据不足（只是同场出现）就**不要**写关系。同场 ≠ 有关系。

汇总时分流：

- **稳定关系** → 实体卡 `relations_graph`：跨阶段长期成立（出现在 ≥ 2 章，或覆盖该角色出场章
  的 ≥ 70%）。
- **时变关系** → 阶段卡 `relations`：只在该阶段成立的上下级、护卫、君臣等。
- 同一对关系在不同阶段类型不同时（先「上下级」后「结义兄弟」），分别放进对应阶段卡。
- 同一 `(target, type)` 跨章重复 → 合并为一条，`sources` 保留全部章号与引用。

## 5. 阶段切分信号（汇总阶段执行，逐章只给 `phase_hint`）

当以下任一字段发生**不可逆**的明显变化时，开启新阶段：

| 信号 | 例子 | 权重 |
|---|---|---|
| `identity` | 卖面摊贩 → 顾府书僮 → 军中参谋 | 最高（优先按身份转变切） |
| `age` | 二十七八岁 → 三十岁不到 | 次高 |
| `appearance` | 眉清目秀 → 身形高大，体格壮硕 | 再次 |
| `clothing` | 破烂衣衫 → 胄甲 | 辅助 |
| `location` / `phase_hint` | 长期活动地域改变 | 辅助（由逐章 `phase_hint` 承载） |

**不算阶段切分**的临时状态：受伤、生病、换一套衣服、短时间伪装、单章的身份口误。
它们留在当前阶段内，或写进该阶段正文的备注。

切分粒度：

- 优先按**身份转变**切，其次年龄跨越，再次长期外貌变化。
- 每个阶段**至少 2 章**；只有 1 章且变化剧烈时并入相邻阶段并标注 `[短暂]`。
- 阶段章节**互不重叠**，且只记该角色实际出场的章（中间缺席的章不纳入）。
- 相邻且 `phase_hint` 相同的阶段必须合并回一段。

## 6. 字段填写约定（逐章）

| 字段 | 约定 |
|---|---|
| `name` | 最正式称呼；必填，非空 |
| `aliases` | 字符串数组（**本章**出现的）；无别名写 `[]` |
| `gender` | 只能是 `男` / `女` / `未知`；原文未明确写 `未知` |
| `age` | 年龄数字或原文描述（`十八九岁`、`中年`、`花甲之年`）；未知写 `""` 或 `[不确定]` |
| `identity` | **本章**身份/职业，尽量用原文词（`捕快`、`掌门`、`客栈掌柜`） |
| `appearance` | **本章**外貌原文描述，不要润色；无描写写 `""` |
| `relations` | 数组，可为 `[]` |
| `phase_hint` | 阶段提示（见第 7 节）；无法判断写 `""` |
| `confidence` | `高` / `中` / `低` |
| `sources` | **本 skill 扩展字段**（见第 8 节），引用数组 |

**禁止**在任何字段里写推断、脑补、跨章知识、朝代背景考据。只搬本章原文。

## 7. `phase_hint`（逐章阶段提示）

`phase_hint` 是**提示**，不是切分结果：逐章子代理**不生成阶段卡、不编号阶段**，只回答
"这一章里的他，处在什么时期"。

写法：

- 用 2–8 个字的**时期短语**，如 `卖面时期`、`书僮时期`、`逃犯时期`、`军中参谋`、`将军时期`。
- 同一时期跨多章时必须用**完全相同的字符串**（否则会被切成多段阶段）。
- 只描述身份/处境，不要复述原文句子、不要写年龄数字、不要写章节号。
- 判断不了就写 `""`；汇总阶段会退化为按 `identity` / `age` / `appearance` 变化切分。

汇总时的容错：`书僮时期` / `书僮` / `书僮阶段` 这类**纯后缀差异**会被归一为同一阶段
（见 `references/aggregation-rules.md` 第 2 节第 0 步），但**语义不同**的提示不会被合并——
所以仍应按上面的写法保持字符串一致。

## 8. 溯源（sources）

为让人物卡与阶段卡能填出"原文依据"和关系依据，本 skill 增加**可选**字段：

```json
"sources": [
  { "chapter": 0, "quote": "……原文片段，不超过50字……" }
]
```

- `chapter` 必须等于本章 `chapter_index`。
- `quote` 必须逐字来自本章原文，不得改写、拼接、跨段合并；长度 ≤ 50 字。
- 一人一条即可；有多处关键依据时最多 3 条。
- schema 中该字段可选（保证最小规范形态也能通过校验），但**提取时应尽量填写**——没有它，
  卡片正文的"原文依据"只能留空。

## 9. 同名不同人

同名（或同一称呼指两人）时的区分顺序：

1. **身份**：`identity` 不同则视为两人（`王掌柜` 与 `王捕头` 同名不同人）。
2. **关系**：关系网指向不同（一个是"李寻欢的仆人"，一个是"李寻欢的仇敌"）。
3. **章节上下文**：本章场景/地点/时间线。

处理方式：

- 能区分 → 各建一条，`name` 可加限定语避免混淆（如 `王掌柜（客栈）`），并在 `aliases` 保留原文称呼。
- **无法区分 → 合并为一条**，把两种可能写进 `identity` 或 `appearance`，`confidence` 标 `低`，相关值后加 `[不确定]`。
- 绝不为了凑区分而编造身份。
- 汇总约束：某称呼若是**另一个角色**的主名，则不并入本角色实体卡的 `aliases`（宁可漏一个别名，
  也不要把两个人混成一个人）。

## 10. 置信度规则

| 置信度 | 判定条件 |
|---|---|
| `高` | 有姓名，且本章有对话或明确身份/行为描写 |
| `中` | 有姓名但本章只有提及、无对话无明确动作；或有稳定称呼+对话 |
| `低` | 只有称呼、代词、转述；或同名不同人无法区分；或身份/关系仅能猜测 |

- 标 `低` 时：在**具体值**后加 `[不确定]`，例如 `"identity": "疑似店小二 [不确定]"`，`"gender": "未知 [不确定]"`。
- `confidence` 是整条角色的总评；单个字段不确定不影响其他字段已确证的部分。
- 不确定时**不要**直接删除该条；保留 + 标 `[不确定]` + 标 `低`，让汇总阶段有据可查。
- 汇总时：实体卡 `confidence` 取各章**最高值**；阶段卡 `confidence` 取该阶段内**最低值**
  （阶段是"能一起用"的承诺，取最低更安全）。

## 11. 自检清单（每章收尾）

- [ ] 每条 `name` 非空，且本章原文真的出现过。
- [ ] 别名都在本章 `aliases`，没有独立条目；没有把别的时期的称呼写进本章。
- [ ] 每条 relation 有 `target` 和 `type`，且方向正确。
- [ ] 无名龙套没有被写进来。
- [ ] `phase_hint` 是 2–8 字时期短语，或为空串；没有复述原句、没有写章号。
- [ ] `confidence` 为 `低` 的条目，值后都带 `[不确定]`。
- [ ] 没有任何推断、补充、跨章信息。
