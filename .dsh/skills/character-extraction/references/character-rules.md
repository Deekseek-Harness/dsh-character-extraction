# 人物提取规则

适用对象：单章提取时的 `characters` 数组。字段定义见 `schemas/character.schema.json`。

## 1. 提取范围

- **只提取本章出现的人物。** 判断依据是本章原文，不是全书知识、不是前几章的记忆。
- 不要因为某人在前文重要就补写他；不要因为某人"应该在场"就写他。
- 不要跨章累积：处理第 N 章时，前 N-1 章的提取结果不属于本章输入。

## 2. 什么算"人物"，什么不算

**提取**（满足任一条）：

- 有姓名（含姓、名、字号、法号、绰号）。
- 有对话（引号内的发言），且说话人可判定。
- 有明确身份指称并能稳定指代某个体（如"那掌柜的""李府管家"），本章内可追踪。

**不提取（无名龙套）**：

- 无姓名、无对话、仅一笔带过：`众人`、`百姓`、`群雄`、`一个伙计`、`数名侍卫`、`路人`。
- 群体称呼：`三人`、`诸将`、`众弟子`。哪怕群像描写很详细也不提取。
- 纯环境拟人：`风`、`影子`。除非原文明示为人物。

判定不确定时：**倾向不提取**。宁可漏一个龙套，不要造一个角色。

## 3. 别名、绰号、称号

- 全部放进 `aliases` 数组，**不要**为同一人物的别名单独建条目。
- 覆盖：绰号（`黑旋风`）、称号（`及时雨`）、尊称（`李老爷`）、贬称（`那厮`，能确定指代时）、法号/道号、化名、官职代称（`李提辖`）、排行称呼（`三郎`）。
- `name` 取**最正式、最具辨识度**的称呼：优先"姓+名"，无姓名则取最稳定的称呼。
- 别名要能在本章原文中找到出处；不要凭读音猜测变体、不要补全姓氏。
- `aliases` 去重，不含 `name` 本身。

## 4. 关系（relations）

- 关系必须**标明方向**：`target` 是被指向的对方，`type` 是从本角色出发看过去的关系。
- 方向示例：`{"target": "李寻欢", "type": "结义兄弟"}` 写在角色 A 的条目里，表示"A 视李寻欢为结义兄弟"；不要依赖对方条目反推。
- 反向关系可在对方条目中各自记录，两侧独立、不互相推导。
- 关系类型用简短稳定的词：`父`、`母`、`子`、`女`、`兄`、`弟`、`姐`、`妹`、`夫妻`、`师徒`、`师兄弟`、`主仆`、`上下级`、`结义兄弟`、`同门`、`仇敌`、`旧识`、`恋慕`、`未婚夫妻`。
- `target` 必须是**人名**，不是代词。原文只出现"她""那人"时，无法确定就标 `[不确定]`。
- 每条关系建议带 `quote`（可选字段），用于人物卡的"关系-依据"列；没有引文时该列留空。
- 单章内关系证据不足（只是同场出现）就**不要**写关系。同场 ≠ 有关系。

## 5. 字段填写约定

| 字段 | 约定 |
|---|---|
| `name` | 最正式称呼；必填，非空 |
| `aliases` | 字符串数组；无别名写 `[]` |
| `gender` | 只能是 `男` / `女` / `未知`；原文未明确写 `未知` |
| `age` | 年龄数字或原文描述（`十八九岁`、`中年`、`花甲之年`）；未知写 `""` 或 `[不确定]` |
| `identity` | 身份/职业，尽量用原文词（`捕快`、`掌门`、`客栈掌柜`） |
| `appearance` | 外貌原文描述，不要润色；无描写写 `""` |
| `relations` | 数组，可为 `[]` |
| `confidence` | `高` / `中` / `低` |
| `sources` | **本 skill 扩展字段**（见第 7 节），字符串引用数组 |

**禁止**在任何字段里写推断、脑补、跨章知识、朝代背景考据。只搬本章原文。

## 6. 同名不同人

同名（或同一称呼指两人）时的区分顺序：

1. **身份**：`identity` 不同则视为两人（`王掌柜` 与 `王捕头` 同名不同人）。
2. **关系**：关系网指向不同（一个是"李寻欢的仆人"，一个是"李寻欢的仇敌"）。
3. **章节上下文**：本章场景/地点/时间线。

处理方式：

- 能区分 → 各建一条，`name` 可加限定语避免混淆（如 `王掌柜（客栈）`），并在 `aliases` 保留原文称呼。
- **无法区分 → 合并为一条**，把两种可能写进 `identity` 或 `appearance`，`confidence` 标 `低`，相关值后加 `[不确定]`。
- 绝不为了凑区分而编造身份。

## 7. 溯源（sources）

全局规则要求"每条信息必须有 `quote` 溯源"，但单章 `characters` 的规定字段里没有 `quote`。为让人物卡能填出"原文依据"和关系依据，本 skill 增加**可选**字段：

```json
"sources": [
  { "chapter": 0, "quote": "……原文片段，不超过50字……" }
]
```

- `chapter` 必须等于本章 `chapter_index`。
- `quote` 必须逐字来自本章原文，不得改写、拼接、跨段合并；长度 ≤ 50 字。
- 一人一条即可；有多处关键依据时最多 3 条。
- schema 中该字段可选（保证最小规范形态也能通过校验），但**提取时应尽量填写**——没有它，人物卡的"原文依据"只能留空。

## 8. 置信度规则

| 置信度 | 判定条件 |
|---|---|
| `高` | 有姓名，且本章有对话或明确身份/行为描写 |
| `中` | 有姓名但本章只有提及、无对话无明确动作；或有稳定称呼+对话 |
| `低` | 只有称呼、代词、转述；或同名不同人无法区分；或身份/关系仅能猜测 |

- 标 `低` 时：在**具体值**后加 `[不确定]`，例如 `"identity": "疑似店小二 [不确定]"`，`"gender": "未知 [不确定]"`。
- `confidence` 是整条角色的总评；单个字段不确定不影响其他字段已确证的部分。
- 不确定时**不要**直接删除该条；保留 + 标 `[不确定]` + 标 `低`，让汇总阶段有据可查。

## 9. 自检清单（每章收尾）

- [ ] 每条 `name` 非空，且本章原文真的出现过。
- [ ] 别名都在 `aliases`，没有独立条目。
- [ ] 每条 relation 有 `target` 和 `type`，且方向正确。
- [ ] 无名龙套没有被写进来。
- [ ] `confidence` 为 `低` 的条目，值后都带 `[不确定]`。
- [ ] 没有任何推断、补充、跨章信息。
