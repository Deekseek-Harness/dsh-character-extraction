# 物品提取规则

适用对象：单章提取时的 `items` 数组。字段定义见 `schemas/item.schema.json`。

## 1. 提取范围

提取**本章实际出现**的、可独立存在的器物：

| 类别 | 例 |
|---|---|
| 武器 | 刀、剑、枪、弓、弩、暗器、鞭、棍、匕首 |
| 信物 | 令牌、玉佩、书信、印章、虎符、婚书 |
| 药物 | 丹药、解药、毒药、金疮药、汤剂 |
| 书籍 | 秘籍、账册、地图、经卷、名册 |
| 饰品 | 发簪、戒指、念珠（作为器物时） |
| 日常物件 | 酒壶、灯笼、茶杯、扇子（作为器物时）、包袱、银两、钥匙 |
| 特殊器物 | 机关、法器、宝器、乐器 |

## 2. 什么不算物品

- **衣物/穿在身上的**：长衫、甲胄、腰带、斗笠 → 归 `clothing`。
- **人**：包括随从、坐骑（马属于生物，不提取为物品）。
- **地点/建筑**：`客栈`、`城门`、`密室`。
- **抽象概念**：`内力`、`名声`、`仇恨`、`武功招式名`（招式不是物品；只有实物载体如"秘籍"才是）。
- **纯背景物件**：仅作为环境陈设、无人使用也无人持有（`墙上的字画`若无情节功能则不提取）。

边界处理：**能拿、能给、能藏、能用的实物**才提取。扇子、玉佩等两可项：作为功能器物写 `items`，作为穿戴配饰写 `clothing`，同一章内只写一处。

## 3. 字段

| 字段 | 约定 |
|---|---|
| `name` | 物品名，原文用词优先（`小李飞刀`、`九转还魂丹`、`玄铁令`） |
| `type` | 类型词，见下表 |
| `appearance` | 外观：材质、颜色、大小、纹饰；原文没写写 `""` |
| `function` | 功能/用途，用原文说明；未说明写 `""` |
| `holder` | 持有者姓名（与 `characters` 的 `name` 一致）；无主/散落写 `""` 或 `无人持有` |
| `quote` | **必填**，原文引用 |

`type` 建议词表（择一，不要自造近义词）：`武器`、`信物`、`药物`、`书籍`、`饰品`、`日常物件`、`特殊器物`。

## 4. 原文引用（quote）—— 硬要求

- **必须逐字来自本章原文**，不得改写、概括、拼接不相邻片段。
- 长度建议 ≤ 50 字；截取包含该物品判定的最小完整片段。
- `quote` 要能支撑 `holder` 与 `function` 的判定；如果引文只提到名字没说功能，就把 `function` 留空，不要靠引文之外的推断填写。

## 5. 持有者（holder）

- 写**本章内**的持有者。本章未交代持有者就写 `""`。
- 本章内发生转移（`接过`、`夺走`、`赠予`）→ 在 `function` 或 `appearance` 之外单列不成条；同章转移写最终持有者，并把转移事实留在 `quote` 里。
- 不跨章推断归属（不要用"上一章是李寻欢的"来填本章的 holder）。

## 6. 只提取本章实际出现的物品

- 不提取"应该存在"的物品（人物是剑客 ≠ 本章写了剑）。
- 不提取被泛指的量词集合（`几锭银子` 若未具体化，可提取为 `银两`，`appearance` 写 `若干`）。
- 精神/象征性提及（`心中的剑`）不提取。

## 7. 汇总阶段的合并

同一物品在**多章**出现是常态：

- 单章提取时**不做跨章合并**，本章出现几次就按章内实际出现记录（同名同章多次出现，若描述一致则合并为一条，`quote` 取最有信息量的一处）。
- **合并发生在汇总阶段**：同名物品合并 `holder`（多值去重）、`chapters`（升序去重）、`sources`（每章一条引用）。
- 详见 `references/aggregation-rules.md`。

## 8. 自检清单

- [ ] 每条有非空 `name`、`type`、`quote`。
- [ ] `type` 取自建议词表。
- [ ] `holder` 若填了人名，该人名在 `characters` 中出现过。
- [ ] `quote` 能在本章原文中逐字找到。
- [ ] 没有把衣物、人物、地点写进 `items`。
- [ ] 没有跨章推断持有者与功能。
